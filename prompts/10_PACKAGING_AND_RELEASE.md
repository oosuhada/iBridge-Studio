# Prompt 10 — Packaging and Release Prep

Goal:
Only after the core display pipeline works, prepare user-facing packaging.

Tasks:

1. Build instructions for macOS Primary.
2. Build instructions for Windows Receiver.
3. Quick-start for LAN.
4. Quick-start for Thunderbolt Bridge.
5. Troubleshooting:
   - receiver black screen
   - codec missing
   - firewall
   - wrong display
   - poor fps
   - power drain
6. Known limitations.
7. Performance table by mode.

Do not write marketing copy that claims Studio Display equivalence.
