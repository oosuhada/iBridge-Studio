# ADR-0003 — Start with 5K60 first, then downshift with data

Status: accepted

## Context

The user wants 5K60 attempted first rather than starting with a low MVP.

## Decision

Plan A 5K60 raw/near-raw feasibility is the first technical spike. Plan B and C are fallback stages only after measured evidence.

## Consequences

- More ambitious initial benchmark.
- Prevents premature settling for low quality.
- Requires strong logging and clear downshift criteria.
