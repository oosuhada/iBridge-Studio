# Product Context

## Problem

A 2015 27-inch iMac Retina 5K still has a valuable 5120×2880 panel, but it cannot be used as a normal external display by an M1/M-series MacBook without Target Display Mode or hardware modification.

## Product

iBridge is local software that makes the iMac behave as closely as possible to a secondary display by streaming a virtual/captured display from MacBook to iMac.

## Primary user

A developer using an M1/M-series MacBook who owns a 2015 5K iMac currently booting Windows and wants a non-destructive display reuse path.

## User success

The user can code/browse/use tools on the iMac screen with acceptable pointer smoothness and at least one stable 60Hz mode.
